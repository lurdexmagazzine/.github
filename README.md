# Lurdex Magazinne Org Hub

This repository powers the GitHub organization profile and brand reference for the Lurdex workspace.

## What lives here

- `profile/README.md` — the public organization landing page
- `docs/brand/manifesto.md` — the brand story and editorial positioning
- `docs/brand/design-system.md` — visual rules, palette, typography, and copy rules
- `docs/brand/voice.md` — tone of voice and writing guidance
- `docs/brand/working-rules.md` — team identities, commit conventions, and workflow notes
- `docs/ops/tooling.md` — approved external tools and how to keep secrets out of git
